Write a function that reverses a string `s`, returning a new string with its characters in reverse order.

**Example 1:**

```
Input: s = "hello"
Output: "olleh"
```

**Example 2:**

```
Input: s = "AlgoMonster"
Output: "retsnoMoglA"
```

**Example 3:**

```
Input: s = "a"
Output: "a"
```

**Constraints:**

- `0 <= s.length`
- `s` consists of printable ASCII characters
