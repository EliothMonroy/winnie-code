Write a function that finds the maximum element in an array of integers `nums`.

**Example 1:**

```
Input: nums = [3,1,4,1,5]
Output: 5
```

**Example 2:**

```
Input: nums = [-10,-3,-7,-1]
Output: -1
```

**Example 3:**

```
Input: nums = [42]
Output: 42
```

**Constraints:**

- `1 <= nums.length`
- Every `nums[i]` fits in a Kotlin `Int` (`-2147483648 <= nums[i] <= 2147483647`)
