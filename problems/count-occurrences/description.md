Write a function that counts how many times `target` appears in an array of integers `nums`.

**Example 1:**

```
Input: nums = [1,2,3,2,4,2], target = 2
Output: 3
```

**Example 2:**

```
Input: nums = [5,5,5,5], target = 5
Output: 4
```

**Example 3:**

```
Input: nums = [1,2,3], target = 7
Output: 0
Explanation: 7 does not appear in nums.
```

**Constraints:**

- `0 <= nums.length`
- Every `nums[i]` and `target` fits in a Kotlin `Int` (`-2147483648 <= value <= 2147483647`)
